# PhotoAnalyzer

A website (maybe an App in the future) where users can upload their photos to.

It will display EXIF data from digital cameras and smartphones, and plot them to graphs
showing the most used camera settings (eg. ISO, Aperture, Shutter speed).

It will also be able to sort photos into colour "moods" via colour palettes. 

Finally, it will map GPS tags onto a interactive globe, so users can see where they took 
their photos and how often in certain locations (eg. their home).
